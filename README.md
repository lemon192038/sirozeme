# KINGDOMS OF CONQUEST (仮称) — STAGE 1

```
npm install
npm run dev      # 開発
npm run build    # dist/ を生成
```
公開: GitHubにpush → Settings > Pages > Source を「GitHub Actions」に設定。

## 操作
- PC: 左ドラッグ=移動 / 右ドラッグ or Shift+左ドラッグ=回転 / ホイール=ズーム / WASD=移動 / Q,E=回転
- タッチ: 1本指=移動 / 2本指=ピンチでズーム・ひねりで回転
